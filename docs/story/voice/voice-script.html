Voice-acting sheet: chapter 1

Rift Mech Defense. 179 lines, 8 designed voices. Every line has an ID: name its audio file after it.

How to make it in ElevenLabs

  1. Design each voice once. Voices → My Voices → Add a new voice → Voice Design. Paste the voice's prompt, paste its preview text, set the guidance scale shown, generate, and save the best of the three.
  2. Generate the lines in Text to Speech with Eleven v4 (or v3). Paste each line exactly as written, [tags] included: they set the delivery and aren't spoken. Ellipses add pauses; CAPITALS add stress.
  3. Keep every take dry and clean. No radio, crackle or echo in ElevenLabs: the game puts the radio sound and the static over every line itself (decided). Leave about half a second of silence at each end.
  4. Save each file as its ID, lower case, MP3 44.1 kHz: m5_09_copper.mp3. Lines marked "3 takes" get _a, _b, _c.
  5. Work one voice at a time: tap a voice below to show only its lines.
  • Stability: use Creative or Natural so the tags work; Robust follows them less.
  • Speed: leave at 1.0. OVERWATCH's fast lines are fast in the writing.
  • If a tag gets spoken aloud, cut it in editing or try the take again.
  • Squads are fresh each mission, so five squad voices cover all fourteen squads.

Re-take the film's lines: calm takes don't fit a disaster

The 24 lines the cinematic uses are marked FILM. Their tags are rewritten to be frightened, breathless and shouting (the words are the same, so captions and file names still match). Tap Film re-takes to see only those.

  • Use Eleven v3 or v4 with stability on Creative: the tags only bite there.
  • Generate 3 of each and keep the most frightened. Overwrite the old file (same name).
  • Still record them dry. The cinematic's radio adds the speed-up, shake, stutters, dropouts and static, more for worse moments.
  • The one calm line is C1_07 (the three clear seconds): awed and trembling, not panicked.

The IRMD's sensor AI and the voice on the radio. The only thing that can see them. Warm, lives through it with you.

Voice Design prompt

English, neutral American accent, female voice, late twenties, studio quality. A warm, quick, bright woman who is brave but a little nervous, kind and quietly funny. Mid-pitched with a soft, clear tone and a slight breathiness when she is scared. Talks fast when tense and slows right down when something matters.
